TWO CLOCKS RUN AT ONCE. The lower stripe is processing — whose contracts you are closing, running the full RCM to End of RSM. The upper stripe is prospecting, which never stops; at T-2 it switches to feeding the next RCM, exactly 2 weeks out from that month's first processing day. Station recruiting plan for the upcoming month is due NLT the Friday prior to T-2 (UM 3-31, para 1-18). Note the RCM is not the calendar month — DEC RCM opens 27 NOV.
T-2 — PROSPECTING FOR NEXT RCM2 weeks out from the next RCM. Calls now feed next month's mission. Station recruiting plan is due the Friday prior (UM 3-31, 1-18).
